# ChatLog Vision - The Smarter Way to Connect

## Project Overview

ChatLog Vision is a next-generation messaging application featuring:
- **Premium Glass UI** with frosted glass effects and smooth animations
- **Smart Messaging** with AI-powered features
- **Moments** for sharing stories and experiences
- **HD Calls** with video, screen sharing, and live captions
- **Communities** with channels and moderation
- **Chatiee** - AI assistant available everywhere
- **End-to-End Encryption** for security
- **Cloud Sync** across multiple devices

## Tech Stack

### Frontend (Mobile)
- **Flutter** - Cross-platform mobile app
- **Figma** - UI/UX Design

### Backend
- **Node.js** - Runtime
- **Express.js** - Web framework
- **MongoDB** - Database
- **Firebase** - Authentication & Push Notifications
- **Socket.IO** - Real-time Messaging

### DevOps
- **Docker** - Containerization
- **Nginx** - Reverse Proxy
- **GitHub Actions** - CI/CD
- **Git** - Version Control

## Quick Start

### Prerequisites
- Node.js 18+
- Flutter 3+
- MongoDB
- Docker (optional)

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

### Mobile Setup

```bash
cd mobile
flutter pub get
flutter run
```
